Agetra Terminal v0.2.4｜Windows x64 便携版使用教程

一、最快开始

本包仅适用于 Windows x64（64 位电脑）。Mac 不能使用这个包。
已内置运行环境和依赖，无需安装 Node.js、npm，也不用输入命令。

1. 把收到的 ZIP 压缩包「全部解压」到本机普通文件夹（例如 C:\Agetra；不要放在网络共享目录）。
2. 打开解压后的文件夹，双击「启动.cmd」。
3. 稍等片刻，浏览器会自动打开实时面板：http://127.0.0.1:4318

弹出的黑窗口就是本地服务，请保持打开。关闭黑窗口即可停止本地服务；只关闭浏览器不会停止服务。
重复双击启动时，会识别已运行的本面板并打开现有页面。
每次重新启动时，真实交易默认关闭。

想先熟悉界面：双击「演示.cmd」，浏览器打开 http://127.0.0.1:4319 。
演示模式使用假代币、假余额和模拟订单，不会发送链上交易。请通过页面的运行模式提示区分实时与演示。

二、只看代币，不用连接钱包

实时监控需要联网，使用公开的 BSC 数据，不需要登录钱包。
仅展示 Binance Agent ID Exclusive 指定模板的已验证代币。后台每轮扫描完成后约 6 秒再扫描，页面每 5 秒刷新；新币要等待 5 个区块确认并完成校验。

左侧「代币雷达」显示经过目标模板校验的代币，可以按名称、符号或合约地址搜索。「仅内盘」默认勾选。
首次启动会从历史区块补扫；出现 backfill / 补扫提示时，请保持程序运行并等待。
列表为空可能是仍在补扫，也可能暂时没有已验证的目标模板代币。这不是 Four.meme 全站代币列表。
若页面显示 error 或 RPC 错误，请先看下面的排错方法。

三、需要使用钱包时

请连接你自己的 Binance Agent Wallet（币安 Agent 钱包）。

1. 点击右侧「连接 Agent 钱包」。
2. 按页面提供的官方连接链接继续，在 Binance App 核对配对码后完成连接。
3. 按需要在 Binance App 开启 Developer Mode，检查其有效期、额度和余额，然后回面板点击「刷新钱包」。
4. 准备交易时，手动开启「真实交易」。有已验证且可交易的内盘目标币后，选择代币、买入金额或卖出持仓比例，点击预览。
5. 仔细核对目标合约、金额、风险、余额及权限变化，再逐笔勾选确认并执行；如 App 要求确认，继续在 App 核对处理。

卖出如果需要授权，先完成本次数量的授权，确认后重新获取卖出预览。预览过期或报价变化时，也要重新预览。
交易状态可在「交易记录」查看。出现等待 App 确认或 UNKNOWN 时，先检查钱包历史，不要连续重试或删除记录来绕过。
关闭黑窗口或关闭真实交易开关，不会撤销已经提交或在 App 中等待确认的请求。

本版已实现真实监控、预览和钱包桥接，但尚未完成目标代币真实交易的完整闭环验证；界面中的「防夹未验证」也请按原意理解。

四、常见问题

- 双击后报缺文件 / 一闪而过
  先确认已经「全部解压」。不要在压缩包预览窗口里直接双击。重新解压完整文件后再试，并保留黑窗口中的报错文字。

- 浏览器没有自动打开
  确认黑窗口仍在运行，手动在浏览器输入：
  实时：http://127.0.0.1:4318
  演示：http://127.0.0.1:4319
  这两个地址只在运行程序的本机使用。

- 页面显示 RPC error / error，或数据停止更新
  先检查网络，等待后点击页面「刷新」。公共 RPC 可能限流或不可用；点击右上角「RPC 节点」（手机上为齿轮），选择自定义节点并填写 HTTPS 地址。先「测试连接」，再「保存并应用」；需要时可「恢复默认节点」。保存后实时模式立即应用，演示模式用于下次实时启动。切换到演示模式可先确认本地界面是否正常。

- 提示端口已被占用
  实时使用 4318，演示使用 4319。正常重复启动会复用本面板。若被其他程序占用，先关闭之前的本面板黑窗口再重试；仍有提示则联系提供者，不要随意结束不认识的系统进程。

- 提示 DLL / 运行库缺失，或被安全软件拦截
  先确认电脑是 Windows x64，核对压缩包来源和文件是否完整，记录具体提示并反馈给提供者。不要关闭安全软件，也不要下载来路不明的 DLL。

五、怎么转发给朋友

只转发收到的成品 ZIP 压缩包，让朋友自己全部解压并连接自己的钱包。
不要把你已经运行过的整个文件夹重新打包发送，也不要发送个人登录资料、配对信息、钱包会话、私钥或个人运行记录。

六、自定义 RPC

支持带 API Key 的 HTTPS BSC 主网 RPC。测试连接会检查网络、最新区块和日志查询，并显示响应时间。
配置只保存在这台电脑，地址默认隐藏；已保存的密钥不会回显，编辑时留空可继续使用。
实时模式切换节点时会清除旧预览并关闭真实交易开关；有未完成订单时，先核对订单后再切换。
RPC 用于行情、模拟和回执读取；钱包的交易广播由 Binance Agent Wallet 处理。
不要分享 .runtime/rpc-settings.json、个人 .env 或钱包运行记录。
